Всего существует три вида преобразований: в строку, в число и в логическое (булево) значение. 
Вот правила чтобы распутать сложные выражения:
1. **Правило «Магического Плюса»** 
> Если в операции есть `+` и хотя бы одна строка — всё превращается в строки и склеивается. Во всех остальных математических операциях (`-`, `*`, `/`, `%`) всё всегда превращается в числа.

Например:
```
"5" + 2 // "52"
"5" - 2 // 3
```

2. **Правило «Унарного знака»** 
> Знак, который стоит вплотную перед ОДНИМ значением (минус или плюс), — это команда «переведи в число прямо сейчас». 

Например:
```
-"5" //5
```

3. **Правило «Разделяй пробелом»**
> Два минуса или плюса подряд без пробела (`--` или `++`) — это инкремент/декремент. Если между ними есть пробел (`- -`), это две разные операции.

Первый минус — это математическое вычитание.
Второй минус — это унарный знак (из правила №2), который привязан к следующему числу.

4. **«Пустой массив — это пустая строка»**
> Если в математику или строки попадают объекты или массивы, JS пытается превратить их в примитивы.

Например:
```
[] // ""
[5] // "5"
{} // "[object Object]"
```

5. **«Логика ленива»**
> `||` ищет **первую истину** и возвращает её ; `&&` ищет **первую ложь** и возвращает её.
